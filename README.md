# Federal Register — Index

The Federal Register is the daily journal of federal agencies: proposed and
final rules, executive orders, and public notices. It is the official
publication that makes regulations legally effective.

## Official sources
- Current issue: https://www.federalregister.gov
- API (free key): https://www.federalregister.gov/developers/documentation/api/v1
- Bulk XML: https://www.govinfo.gov/bulkdata/FR

## Key document types
- **Rules** — legally binding regulations
- **Proposed Rules** — open for public comment (usually 30–60 days)
- **Notices** — meetings, agency actions, information collections
- **Presidential Documents** — executive orders, proclamations, memoranda

*Index only — issues are published daily and cannot be mirrored.*
